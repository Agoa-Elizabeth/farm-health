Farm Health Advisory React Native App

Setup:

cd rn-app
npm install
npm start

Then open the app with Expo on Android/iOS or web.

The app uses the Django backend at `http://10.0.2.2:8000/api` by default. Update `app.json` if your backend is hosted elsewhere.

Screens:

- Login
- Sign Up
- Farm Dashboard
- My Reports
- Submit Report
- Outbreak Map
